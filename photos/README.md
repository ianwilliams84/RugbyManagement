# Player photos

Drop player photos into this folder using the player's id as the filename — for example `p01.jpg`, `p07.png`. The id matches the `id` field in `data/squad.json`.

Photos are referenced by the **Lineup Photo** generator. The featured player's image bleeds into the right side of the graphic, England-Sky-Sports style. For best results:
- Use a portrait crop (taller than wide), 800–1200 px on the long edge
- Cut-out backgrounds (transparent PNG) look most professional
- Whole-team group shots: not used here

This folder is gitignored — only this README is committed.
